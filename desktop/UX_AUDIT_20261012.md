# Browser service audit — 2026-10-12

Scope: the currently released browser gateway, based on c48b794. Android APK and desktop applications are not modified by this pass.

## Changes

- Friendly request errors for lost connectivity, expired login, denied access, absent materials, concurrent edits, oversized files, throttling, and unavailable services. Non-JSON gateway errors no longer expose parser text.
- Bounded requests: ordinary feature requests time out at 60 seconds, file requests at 180 seconds. Closing a section still cancels its requests. Timeout instructions say to refresh and check whether the action already completed; mutations are never automatically retried.
- Expired authenticated feature/chat-history requests lock local account data and open sign-in.
- Correct sidebar icons and workspace/settings grouping; opening a section resets its scroll position and focuses its heading.
- Optional profile name can be cleared. Pagination retains its retry button after request failure.
- Readable Markdown research export alongside the existing complete JSON export. Status and common result field labels use readable Russian text.
- Online speech preview is usable without a device speech-synthesis engine when an online voice is selected.
- Guest processing logs contain stage names and elapsed milliseconds only, without prompts, answers, account IDs or credentials.

## Validation

- 148 Python tests across browser chat, guests, search, feature routes, voice routes, work and Upwork passed.
- 46 JavaScript tests passed, including non-JSON errors, expired authentication, network loss, throttling and cancellation.
- Chromium synthetic browser acceptance passed for chat/login/history/Flash/PRO/token gating/stop/logout and responsive layout.
- Feature UI acceptance passed across projects, research, medical tools, agents, autopilot, plugins, balance, Studio and voice, including file viewers and screen widths 360–1440 px.
- Synthetic speech lifecycle and full-app voice routing passed. Online speaker profile, emoji removal, late download cancellation, microphone resumption, multi-phrase responses and online speech without device TTS passed.
- Work/earnings UI acceptance passed: unavailable/unknown balances remain explicit, provider errors remain visible, unsafe artifact markup is escaped, and no payment was sent.

These synthetic results validate application behavior, not real microphones, generated media, clinical accuracy, paid payments, completed earnings, or physical Safari/Android devices.

## Live observation and remaining quality gate

One public guest Flash request received HTTP 200 and a complete answer. The total observed duration was 128.41 seconds; Railway recorded 124.18 seconds server-side. Gateway CPU usage was low during the observed window. The responsible stage has not yet been isolated. Stage timing instrumentation is included; an improvement in live latency is not claimed.

A response about local storage also used an overly broad privacy assurance. The browser system instruction now explicitly rejects absolute security/access guarantees. This prompt change is not proof of factual correctness across all questions.

Before broad release: measure first content and completion latency after deployment; validate real Android Chrome and iPhone Safari, permissions and noisy speech; validate each enabled media/medical provider through an authorized real account. Never replace these checks with fixture results or claim all providers are available from UI screenshots alone.
